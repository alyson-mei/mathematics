Существует объединение $\bigcup X$ элементов множества данного множества $X$:
$$\forall X \ \exists Y \ (u \in Y \leftrightarrow \exists v \ (v \in X \wedge u \in v))$$
Дополнительно:
- $X \cup Y$, $X \sqcup Y$
- $\{X_1, ..., X_n \} = \{X_1, ..., X_{n-1}\} \cup \{ X_n\}$

\* снимаем уровень вложенности: $\bigcup \{ \{ a, b \}, \{ c, d\} \} = \{ a, b, c, d\}$
