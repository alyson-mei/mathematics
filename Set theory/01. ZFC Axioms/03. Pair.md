Для множеств $X$, $Y$ существует пара $\{X, Y\}$: 
$$\forall X  \ \forall Y \ \exists Z \ (\forall u \ (u \in Z \leftrightarrow (u = X \vee  u = Y))$$

Дополнительно:
- Синглетон:
$$ \{ X\}$$
	$X = Y = \emptyset$ $\Rightarrow$ $\exists Z$ с одним элементом - пустым множеством; $Z = \{ \emptyset \}$
- Упорядоченная пара: $$(X_1, X_2) = \{ X_1 , \{X_1, X_2 \}\}$$
- Вообще, все наследственно конечные множества
