5\. Принцип возвратной индукции
	- Начальный отрезок + шаг перехода 
$$(\forall \in \mathbb{N}) \ ((\forall m < n) \ X(m) \rightarrow X(n)).$$
Тогда $(\forall n \in \mathbb{N}) X(n)$, т.е. $\mathbb{N} \subseteq X$

6\. Принцип минимального элемента. Минимальные элементы множества:
$$\mathrm{Min}(X) := \{ n \in X \mid \neg (\exists m \in X) \ m < n \}$$
Для непустого $X \subseteq \mathbb{N}$ множество минимальных элементов непусто.
