Inf + Sep => Nat: $$\exists X \ (\mathrm{Ind}(X) \wedge \forall Y \ (\mathrm{Ind(Y)} \rightarrow X \subseteq Y))$$
$X_0$ - индуктивное => берём все такие индуктивные, что если $\in$ в $X_0$, то $\in$ в любом индуктивном: $$\mathbb{N} := \{ x \in X_0 \mid \forall X \ (\mathrm{Ind}(X) \to x \in X) \}$$Отсюда $\mathbb{N} \subseteq$ любому индуктивному, и также $\mathrm{Ind}(\mathbb{N})$:
- $\emptyset$ лежит, т.к. в любом индуктивном
- данное $u$ лежит во всех индуктивных => $u \cup \{ u\}$ лежит во всех индуктивных => лежит в $\mathbb{N}$
