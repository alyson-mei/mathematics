4. Степень | $\mathcal{P}(X) \simeq 2^X$
5. Объединение | $\forall X \ \exists \bigcup X \ \forall y \ (y \in \bigcup X \leftrightarrow \exists x \ (x \in X \wedge y \in x))$

2\. Конструкции
1. Базовые множества
	- $A \cup B = \bigcup \{ A, B\}$
	- $A \cap B = \{x \in A \cup B \mid x \in A \wedge x \in B \}$
	- $A \setminus B = \{ x \in A \mid x \not \in B\}$
	- $(a, b) = \{ \{a \}, \{a, b\} \} \in \mathcal{P}(\mathcal{P}(A \cup B))$; $A \times B = \{ x \in \mathcal{P}(\mathcal{P}(A \cup B)) \mid \exists a \in A, b \in B \ (x = (a, b))\}$
